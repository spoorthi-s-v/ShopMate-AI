# ShopMate AI – AI-Powered E-Commerce Assistant

## Razorpay AI Builder Internship 2026
**Track:** AI Growth & Agentic Commerce

### Problem
Online shoppers often spend too much time searching through products and deciding what fits their needs.

### Solution
ShopMate AI is a lightweight AI-assisted product discovery prototype. Users describe what they want in natural language, and the system returns relevant products and a conversational explanation.

### Features
- Natural-language product search
- Personalized product recommendations
- Budget-aware recommendations
- Category and use-case matching
- Simple AI assistant interface
- Flask REST endpoint
- Responsive web UI

### Tech Stack
- Python
- Flask
- HTML
- CSS
- JavaScript
- JSON product data

### Run locally
```bash
python -m venv venv
# Windows: venv\Scripts\activate
# macOS/Linux: source venv/bin/activate
pip install -r requirements.txt
python app.py
```

Open `http://127.0.0.1:5000`.
